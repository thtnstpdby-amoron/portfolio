Specimen

JAV Fishing E-Commerce

an E-Commerce website built for fishing lure business, built optimized for fast load time, maximal performance. Stateless and bloat-free website. with an automated whatsapp and email checkout logic.

This project is a specimen, I have offer the business owner that they could use this website, and now they're still considering it. I build it by my own, Implementing a headless architecture, utilizing WordPress exclusively for backend data and content management.

Responsive Design

This website run on css optimized for mobile device that then overrided for desktop
making it responsive and user-friendly across all devices.

Minimal Plugin Usage

Minimalized usage of WordPress plugin for efficiency, customized entirely.
I only use one plugin here, that is ACF, for easy content management, that later connected to the headless CMS frontend.

Automated Checkout Process

Built for easy transaction process, I use automation for WhatsApp and email checkout logic with JavaScript.
using this logic, buyer can pick one or multiple product, the JavaScript handles the list, and will be converted to a text based message for the buyer to send it to admin.

Headless CMS

Headless CMS, it is a way to bypass the WordPress's traditional frontend rendering, that hae a lot of confusing UI(for beginner)
that is a bit overwhelming for a user that just need to add a few thing and done. so in this custom headless CMS, I design it pretty simple, admin could just pick what they want to do like edit a page, manage product and reviews, in a simpler, easy to understand interface
